# Olist E-commerce Power BI Dashboard

## Overview
Interactive dashboard on Brazilian e-commerce data (Olist).

## Tools
Power BI Desktop, MySQL

## KPIs
Total Sales, Total Orders, Total Customers, Average Review Score

## Visuals
Monthly sales trend, Top 10 sellers, Top 10 states,
Payment types, Order status, Category sales

## Filters
Year and State slicers
